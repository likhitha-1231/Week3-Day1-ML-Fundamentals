# 📊 Student Performance Prediction using Machine Learning

## 📌 Project Overview
This project predicts student marks using Machine Learning (Linear Regression) based on study-related features.
## 🎯 Objective
To predict student performance using:
- Study Hours
- Attendance
- Assignments
## 🧠 Algorithm Used
- Linear Regression
## 📂 Dataset
- student_performance.csv
https://github.com/likhitha-1231/Week3-Day1-ML-Fundamentals/blob/main/student_performance.csv
## ⚙️ Workflow
Data Collection → Preprocessing → Training → Testing → Prediction → Evaluation
## 📊 Evaluation Metrics
- MAE
- R² Score
## 📈 Output
Model predicts student marks based on input features.
## 💻 Tools Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
